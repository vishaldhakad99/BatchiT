## 🛡️ Reporting a Vulnerability

Security and user privacy are foundational pillars of **BatchiT**. If you discover a potential security vulnerability within our encryption implementation, authentication flows, or API endpoints:

1. **Do not disclose the issue publicly** in an open GitHub issue or public forum.
2. Email the maintainers directly with details of the vulnerability, proof of concept, and affected components.
3. Include information on:
   - Reproduction steps.
   - Potential impact.
   - Any suggested mitigations.

We will review your submission and respond within 48 hours to coordinate a responsible patch and release.
